# ADR-0002: PostgreSQL + Drizzle; PGlite for tests

Status: accepted

## Decision
- PostgreSQL 16 (Docker Compose for dev, port 54329). Drizzle ORM; SQL migrations generated by drizzle-kit into `packages/db/drizzle/`, plus a hand-written migration for triggers.
- Tests run against **PGlite** (Postgres compiled to WASM, in-memory): real SQL semantics (`FOR UPDATE SKIP LOCKED`, plpgsql triggers, `percentile_cont`) without Docker.
- `DATABASE_URL` selects the driver: `postgres://…` (node-postgres) | `memory:` | `pglite:<dir>`.

## Consequences
+ Integration tests are fast and hermetic.
− PGlite is single-connection; never use it for web + worker together.
